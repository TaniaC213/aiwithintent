Six starting points for better results

Start here if Claude still feels like a chat window you copy-paste into. Some of these you set up once, some are just worth understanding, but all six change the results you get from here.

Projects

a dedicated workspace where related chats, files, and instructions live together

What it is: A dedicated workspace inside Claude where you store instructions, upload files, and keep related chats together, so Claude doesn't forget what you're working on every time you open a new chat. The instructions field inside a Project (sometimes called "custom instructions" or "project instructions") is where you set the standing rules for that Project, tone, format, things to always or never do, so you're not repeating yourself in every chat inside it.

When you'd use it: Anywhere you do the same kind of work repeatedly (client comms, content planning, admin for one area of your business). Set up the Project once with your voice, your files, your context, and every new chat inside it starts with all of that already loaded.

Heads up: Now that Chat and Cowork share one interface, a Project works the same way whether you're having a conversation in it or handing it a longer task, one workspace either way.

Example: A Project called "Client emails" with your tone guidelines, a few sample replies you like, and a note about how formal you want to be. Every time you paste a new message to respond to, Claude already knows how you write.

Knowledge Base

the files you upload into a Project for Claude to reference

What it is: The files you upload into a Project so Claude can reference them. Your service menu, your brand guidelines, a client brief, a transcript, anything Claude might need to look at regularly.

When you'd use it: When you have information that doesn't change much but Claude needs to know. Rather than pasting it into every chat, you put it in the Project's knowledge base and Claude can access it automatically whenever it's relevant.

Heads up: "Knowledge base" isn't always a button labelled that way. In a Project it's usually just the section where you add files and instructions. The term comes up a lot in the AI world, so worth knowing what people mean.

Example: Your "Client Onboarding" Project has your welcome document, your intake form template, and your FAQs uploaded. When a new enquiry comes in, you can say "draft a response using my intake form language" and Claude has it.

Cowork Global Instructions

settings you fill in once so every Cowork session already knows who you are

What it is: Settings you fill in once (Settings → Cowork → Global Instructions → Edit) so every Cowork session already knows your business, your shorthand, and how you like output delivered, before you've said a word.

When you'd use it: From day one, ideally. It's the fastest way to stop re-explaining yourself in every new chat or task.

Heads up: This is different to Memory (below). Global Instructions is something you write on purpose. Memory is what Claude picks up on its own as you go. They work together, but filling in one doesn't fill in the other. There's a separate "Instructions for Claude" setting under Settings → General that applies everywhere (web, mobile, desktop, every kind of chat), while Global Instructions applies to Cowork specifically. Worth filling in both if you use Claude across devices.

Example: Global Instructions that say "I run a small skincare business, Australian English, warm not corporate tone, always ask before assuming a client's name." Every new chat or task starts already knowing that.

Memory

Claude remembering things about you across different conversations

What it is: Claude remembering things about you and your work across conversations, so you don't have to reintroduce yourself every time. You can see what it's remembered, edit it, and turn it off if you prefer.

When you'd use it: It's on by default for most users. Helpful for the basics: your business, your tone, recurring projects. You can also ask Claude directly: "remember that I prefer short replies" or "forget what you know about my old business name."

Where to find it: Click your name in the bottom left-hand corner, then Settings, then Capabilities. Under Memory you'll see two toggles, "Search and reference chats" and "Generate memory from chat history." Turn both on, and from that same screen you can view and manage what Claude's storing about you, and edit or correct anything that's wrong.

Heads up: Memory is different from a Project, and different from Global Instructions. A Project is a workspace you organise on purpose. Global Instructions are rules you write once. Memory is background continuity Claude builds up on its own, without you writing anything. All three work well together, but they're not the same thing.

Example: You start a new chat and ask "help me with a LinkedIn post." Claude already knows you run an AI education business, prefer Australian English, and don't want corporate language, because it remembers from previous chats.

Model Differences

Opus, Sonnet, Haiku: different sizes of Claude for different jobs

What it is: Claude isn't one model, it's a family of them at different sizes. Opus is the smartest and slowest, built for genuinely complex work. Sonnet is the everyday workhorse and the default for most real work. Haiku is the fastest, for quick, high-volume tasks where speed matters more than depth.

When to use which: Drafting a newsletter, Sonnet. Reviewing a 40-page tender and pulling out what's relevant, Opus. Sorting 200 feedback comments into themes, Haiku.

Heads up: Worth getting a feel for this early, not later. Picking the wrong model isn't just a quality issue, it can burn through your usage limits unnecessarily (reaching for the slowest, priciest model for something simple) or leave you with a shallow, half-baked answer (using the fastest model for something that actually needed real depth). Check the model selector before you're deep into a task, not after. There's also a top tier that occasionally shows up in the news, aimed at enterprise and research use, not something you'll pick from your own model selector day to day. Don't worry about it.

Example: Drafting a newsletter: the everyday model. Reviewing a 40-page council tender and pulling out what's relevant: the most capable model, for genuinely complex work. Sorting a list of 200 feedback comments into themes: the fast model, because it's quick and cheap at scale.

Context Window

how much Claude can hold in its head at once during a conversation

What it is: How much Claude can hold in its head at once during a conversation. Everything you've said, everything it's replied, plus any files you've attached. It's measured in tokens (roughly, words). The current top Claude models can hold around a million tokens, which is hundreds of pages of text.

When it matters: In very long chats or with very large documents. Claude can start to lose track of things from early in the conversation once the window fills up. If Claude suddenly feels forgetful or inconsistent, the context window is a likely suspect (see the troubleshooting section below for the fix).

Example: You've been working on a content plan in one chat for two hours and Claude starts contradicting things from earlier. Start a new chat, paste in the plan so far, and keep going. Fresh context, clean head.
Prompting basics worth knowing

Get more from what you already type

You've probably seen the usual list: be clear, give context, specify format. All fine, all true, all in every AI article on the internet. These are the moves that actually change the quality of what you get back.

01

Show, don't describe.

Telling Claude "write in a warm, conversational tone" is vague. Warm to whom? Claude fills the gap with its best guess.

Instead, paste in two or three examples of writing you love and say "match this." One good example beats three paragraphs of description.

02

Name what you don't want.

Most advice tells you to describe what you do want. That's half the work.

The other half is a list of banned words or terms not to use: "no words like woven, unlock, journey, dive. No rhetorical questions. No em-dashes. No CTA at the end." Specifics shake loose the AI-voice.

03

Ask for thinking before output.

For anything with real stakes, ask Claude to think it through first before drafting.

"Before you write this, talk me through the key considerations and what you'd recommend." Slows Claude down, surfaces better decisions, and gives you the chance to steer.

04

Give it a role that earns its keep.

"Act as a copywriter" on its own is too generic.

What works is role plus the perspective that role brings: "Act as an editor reviewing this for a small-business audience. Where am I losing them? What would you cut?" The role sets up the questions, that's where the useful feedback comes from.

05

Iterate, don't restart.

When something's 70% right, the instinct is to re-prompt with a bigger version of the original brief. Usually throws away the good bits.

Instead: "Keep the opening. The middle is too generic, make it more specific and cut the metaphor. The ending is fine." Two or three rounds, not eight.

06

Put the ask first, context second.

Long prompts often open with paragraphs of background before the actual request. Claude reads everything, but the thing closest to where it starts writing gets the most weight.

Lead with the ask: "I need a 150-word LinkedIn post about X. Context below." Small change, noticeable difference on longer prompts.

When Claude isn't getting it

The moments everyone hits

Here's what's usually going on, and the fastest way to unstick it.

Claude's giving me something that sounds right but isn't.

What's happening

Claude is trained to sound fluent, which can mean confidently generating something that isn't true: invented statistics, quotes that don't exist, a client testimonial it pulled from nowhere. This is sometimes called "hallucination."

What to do

Ask it to show its source, or tell it explicitly what it is and isn't allowed to invent. For anything you'd actually publish or send, check the specifics yourself: names, numbers, dates, direct quotes. Don't ask Claude to make up case studies, stats, or testimonials you can't verify.

It keeps giving me generic, AI-sounding copy.

What's happening

Claude defaults to a safe, polished register when it doesn't have anything better to work from. Without samples of your actual voice, it reaches for whatever was most common in its training, which is corporate and predictable.

What to do

Give it something real to work from. Paste in two or three examples of how you actually write. Tell it what to avoid as well as what to aim for ("no metaphors about journeys, no words like woven or unlock"). The more specific the negative guidance, the less it defaults to AI-voice.

It's ignoring something I told it a while ago, or the chat's gone downhill.

What's happening

Long chats stretch Claude's attention. The further back an instruction is, the more likely it'll drift, and the same thing happens if you've quietly changed topic inside one long chat, or piled up so many competing instructions Claude can't prioritise. It isn't laziness, it's the conversation getting overloaded.

What to do

For a quick fix, re-anchor the key rule again ("remember: Australian English, no em-dashes") right where it matters. But once a chat's genuinely long, or you've drifted onto something different inside it, the better move is to ask Claude for a handover: "summarise the important info and decisions so far." Start a fresh chat, paste that summary in, and keep going with a clean head instead of an overloaded one.

It's asking me question after question instead of doing the thing.

What's happening

Claude is trying to be careful and not guess wrong. Useful in the right context, annoying when you just want it to get on with it.

What to do

Tell it to make reasonable assumptions and flag them as it goes: "Make sensible assumptions where you have to, just note them at the end so I can correct any that are off." That gives Claude permission to move, and you the chance to adjust.

The output's technically correct but not what I wanted.

What's happening

Usually the brief was ambiguous. Claude interpreted it one reasonable way, and you meant a different reasonable way.

What to do

Don't rewrite from scratch. Say what's wrong and what you want instead: "This is too formal and too long. Keep the structure, cut it in half, make it sound like it could be said out loud." Claude adjusts the existing draft rather than starting over, and you preserve the bits that worked.

Connectors

official links between Claude and apps like Gmail, Calendar, Drive, Notion

What it is: Official links between Claude and apps you already use (Gmail, Google Calendar, Google Drive, Notion, Canva, and hundreds more). Once you connect an app, Claude can read from it, and sometimes write to it, without you copying and pasting. Some connectors come with their own built-in mini-interfaces rather than just fetching data.

When you'd use it: Any time you catch yourself pasting the same kind of content into Claude repeatedly (your calendar for the week, a document from Drive, an email thread). Connect the app once and Claude can just reach for it.

Heads up: You control what Claude can access, and often down to the individual action, not just the whole app. Connecting Gmail doesn't mean Claude reads every email forever, it means Claude can look when you ask it to, with your permission. You can disconnect any connector at any time.

Example: With the Google Calendar connector on, you can ask "what's on my schedule tomorrow and what do I need to prep for?" and Claude pulls the events and gives you a briefing.

Scheduled Tasks

the admin that happens without you, on its own schedule

What it is: Tasks you set up once inside Cowork that then run automatically on a schedule (daily, weekly, on weekdays), or on demand. They can use everything Cowork can: your files, connectors, skills.

When you'd use it: Anything repetitive with a predictable rhythm. A Monday-morning brief that pulls your calendar and top emails. A weekly content round-up. A monthly client report. Set it once, and it runs without you.

Heads up (this changed): Most scheduled tasks now run remotely, on Anthropic's own servers, so your computer no longer needs to stay on and the app open for them to fire. Anything that needs your local files or browser still needs the desktop app open when it runs.

Example: "Every Monday at 7am, check my calendar for the week, summarise any overdue invoices from my Invoices folder, and save it as a markdown file called week-brief.md." You open the file with your coffee.

Skills

the instruction manual you only have to write once

What it is: A reusable set of instructions Claude pulls up automatically when it's relevant, the ones you write yourself are where the real value is.

When you'd use it: Once you've noticed a task you keep re-explaining the same way, brand guidelines, a weekly content format, the exact structure of your invoices. Building a good one takes a real example of what you want and don't want, which is a big part of why this is more of a "secrets up your sleeve" move than a day-one one, you generally need a bit of mileage with Claude first to notice what's actually worth teaching it.

Heads up: Found through the same Directory as Connectors and Plugins now, Customize → Skills → the "+" button.

Example: A skill called "my-brand-voice" that describes how you write (warm, no jargon, Australian English, no em-dashes). Any time you ask Claude to draft something, it applies the skill automatically.

Cowork

Claude working on real, multi-step tasks, not just chatting about them

What it is: Claude working on real, multi-step tasks, reading and writing your actual files, running longer jobs on its own, rather than just a back-and-forth conversation. Chat and Cowork now share one interface, labelled Home in the app: you don't pick a separate app, you describe what you need in the same message box, and if it's a longer job, Claude picks it up as a Cowork task instead of a conversation.

When you'd use it: When "have a conversation with Claude" isn't what you need. Recurring admin, producing a finished deliverable, working across multiple files at once.

Heads up (this changed): Cowork used to be desktop-only and a separate space from Chat. Both of those are now out of date. It's on web and mobile too (mobile still in beta), and it shares a home with Chat rather than living apart from it. Anything touching your local files, your browser, or your screen still needs the desktop app open.

Example: "Go through my /Invoices folder, find anything unpaid more than 30 days old, and draft follow-up emails in a new folder." Claude does the scan, writes the drafts, saves them. You review and send.

Plugins

bundled packs of skills (and sometimes connectors) built for a role or task

What it is: A pre-built bundle of skills, and sometimes connectors, that install together, usually focused on a specific job or role. Think "Sales plugin" or "Legal plugin." Installing a plugin gives you a whole set of related abilities at once, rather than building each one yourself.

When you'd use it: When someone else has already put together what you need. If you're new to a task, browsing plugins can be a fast way to see what's possible before you start writing your own skills.

Heads up: Skills, Connectors and Plugins now all live in the same place: Customize (left sidebar) → the tab you want (Skills, Connectors, or Plugins) → the "+" button → Browse. Same door, three different rooms. Treat plugins like apps you install: have a look at what they do before you enable them, and turn off anything you're not actually using.

Example: You install a "Marketing" plugin and suddenly have skills for brief writing, competitor research, and social copy, without setting any of them up yourself.

Dispatch

triggering a Cowork task from your phone while it runs on your desktop

What it is: A way to start a Cowork task from your phone (via the Claude mobile app) even though the work itself runs on your desktop computer. You send a message, Cowork picks it up on your Mac or PC, does the task, and the result is waiting for you when you're back at your desk.

When you'd use it: When you're away from your computer but think of something you want Claude to do. Commuting, in a meeting, waiting at school pickup.

Heads up: For Dispatch to work, your desktop has to be on and the Claude app running. It's not magic from the cloud, it's your own computer doing the work remotely.

Example: On the train: you message Claude "prep a summary of the Smith client file and draft three possible email replies." By the time you're home, the file is in your folder ready to review.
Under the hood

Take your Claude skills further

You don't need any of this to use Claude well. But if you want to go from comfortable to genuinely fluent, this is where that next level lives.

Artifacts

content Claude produces as a standalone, editable thing in its own panel

What it is: Content Claude produces as a standalone, editable thing in its own panel, rather than just text inside the chat. Documents, code, diagrams, little web apps, tables. You can iterate on them, download them, or keep working on them across the conversation.

When you'd use it: Automatically, most of the time. Claude makes an artifact when it's generating something longer or more structured than a chat reply. Worth knowing the word so you can say "can you put that in an artifact" or "update the artifact with..." instead of scrolling for it.

Example: You ask Claude to write a welcome email sequence. It produces the sequence as an artifact on the right-hand side. You say "make email two warmer" and it edits that artifact directly, so you don't get four full rewrites in the chat.

Claude Design

a canvas for prototypes, slide decks and one-pagers, not paragraphs

What it is: A newer surface for building prototypes, slide decks and one-pagers, rather than a paragraph of text. It has its own spot in the left sidebar, just above your name in the bottom left-hand corner. Available on web (claude.ai/design) and desktop. Not yet on mobile.

When you'd use it: A quick client one-pager, a rough slide deck, a visual mockup you'd otherwise have opened several other apps for.

Heads up: This is closer to its own separate tool and way of working than a small feature bolted onto chat. Worth exploring once you're already comfortable with how Claude produces things generally, not necessarily on day one.

Example: "Turn this into a one-page client proposal" and Claude builds a visual draft you refine through comments and direct edits, rather than more back-and-forth text.

Claude Code

Claude for developers, built for reading and writing actual code

What it is: A version of Claude built for software developers, for working inside code projects: reading files, writing code, running commands, managing version control. It used to be a separate terminal-only install, that's no longer the case, it now sits right inside the desktop app alongside Home (which itself now covers both Chat and Cowork), so you switch between Home and Code.

When you'd use it: Honestly, probably never, unless you're writing software. The reason it's in here: you'll hear people online raving about it, and now you know what they mean and can cheerfully set it aside.

Heads up: Some non-developers do use Claude Code for heavy file work (batch-renaming hundreds of files, reorganising a large project folder, working across many documents at once). If that's you, it's worth a look. For everyone else, Cowork does most of the same jobs without needing this view.

Example of who this is for: A web developer building a client website. They switch to Code in the desktop app and say "add a contact form to the about page and update the navigation." Claude edits the files directly.
Go deeper

Set up your AI headquarters

Everything else in this guide assumes Claude can actually find your business context. This is where that context lives, one system, not five scattered docs and a Downloads folder you've half forgotten about.

What it is

A set of folders, organised by department, that acts as one home base for your business knowledge. Point Claude at it and it always knows where to look, instead of you re-explaining or re-uploading the same things.

Best place to set it up

Wherever you already store files reliably: Google Drive, Dropbox, or straight on your own device. Avoid Downloads, most software treats it differently for security reasons, and avoid ending up with two synced copies of the same folder.

How you structure it

Department by department, not one big pile. Most businesses start with five: brand, offers, clients, content, operations. Add or drop to match how yours actually runs.

Setting yours up:

  1. List your departments (brand, offers, clients, content, operations, or whatever fits your business).
  2. Create one folder per department, wherever you already store files.
  3. Move in what already exists, service menus, brand guides, client briefs, no new writing required at this step.
  4. Point Claude at the specific folder for whatever you're working on that day, not just "my Drive" in general.
Quick reference

Where to find it in Claude

Knowing what something is and knowing where to click are two different problems. This is a rough orientation. The menus do move around occasionally, so treat it as a starting point.

Projects

Left sidebar in the browser or app, look for "Projects" above your chat history. "New Project" button at the top.

Cowork Global Instructions

Settings → Cowork → Global Instructions → Edit. Mirror the essentials in Settings → General ("Instructions for Claude") to cover web and mobile too.

Memory

Your name (bottom left) → Settings → Capabilities → Memory. Toggle on "Search and reference chats" and "Generate memory from chat history," and view or edit what's stored from the same screen.

Skills, Connectors, Plugins

Customize (left sidebar) → the tab you want → the "+" button → Browse. One directory for all three now.

Cowork

Part of Home now, same message box as Chat, on web, desktop and mobile (mobile in beta). Anything touching local files, browser, or screen still needs the desktop app open.

Scheduled Tasks

Inside Cowork → "Scheduled" in the left sidebar. Or type /schedule inside any Cowork task.

Dispatch

From the Claude mobile app, send a message to Cowork. It runs on your desktop and the result shows up in the same thread.

Model selector

Dropdown at the top of the chat window, usually next to or above the message box. Shows the current model, tap to change.

Artifacts

Appear automatically on the right-hand side of the chat when Claude produces them. Nothing to turn on.

Claude Design

Left sidebar, just above your name in the bottom left-hand corner. Or claude.ai/design on the web. Not on mobile yet.

Claude Code

In the desktop app, switch between Home (Chat and Cowork together) and Code at the top of the window.

A note on this guide

Claude changes, so will this guide
