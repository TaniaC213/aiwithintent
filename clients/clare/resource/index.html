Updating CLAUDE.md

When something changes (a new offer, an updated process, a different tool) you never edit the file directly. Just tell Claude:

Claude makes the edit for you. Simple as that.

When you refine a skill through Claude, always ask it to save the update back to your folder as well. The version in Claude and the file in your workspace need to stay in sync. Otherwise you iterate in Claude but the file falls behind.

How to run a task

  1. 1Open Claude Cowork → go to Scheduled → find the task you want
  2. 2Click the three dots next to it, then Run now
  3. 3Claude reads (never edits) your Attendee Tracker to see who's booked or attended that month, and pulls their email addresses for the BCC list — for the Thank-You draft it also pulls Instagram handles for the "here's everyone's handles" section
  4. 4Within a minute or two, the draft appears in your Gmail Drafts folder
  5. 5Open it, read it over, make any tweaks, then send it yourself when you're ready

Quick Tips

Five things that will make a real difference as you get comfortable using this.

1

Update skills in both places

When you refine a skill through Claude, always ask it to save the update to your folder too. The version in Claude and the file saved in your workspace need to stay in sync. Otherwise you iterate in Claude but the file falls behind.

2

Don't let chats run too long

Long chats burn through tokens fast, so Claude has to reread everything each time. When a chat gets long, ask for a handover and start fresh:

Summarise everything we've covered in this chat in a handover document so I can start a fresh conversation.
3

Check your token usage

Go to Settings → your name at the bottom → Usage to see how much you've used in your current session and when it resets. Handy for planning when to do heavier work.

4

Choose your model before you start

Once you've opened a project chat, you can't change the model mid-stream, so pick intentionally at the start:

  • Haiku: quick questions, short tasks, general back-and-forth
  • Sonnet: the everyday workhorse, quality and speed balanced
  • Opus: deep thinking, complex strategy, nuanced analysis
  • Adaptive: Claude decides what each part of the task needs
5

Your skills aren't just for Coffee at the Coast

Your brand voice skill works for anything you write — Pen and Paper Girl client emails, PA in a Day outreach, anything at all — not only Coffee at the Coast content. Next time you're drafting something for the other side of your business, just ask Claude. It already sounds like you.
