Your Mindful Parenting Lifestyle Workspace

This isn't just a folder of files. It's a system where Claude already knows your podcast, your brand, and your workflow before you type your first message. When you open Claude Cowork and select the Mindful Parenting Lifestyle folder as your workspace, Claude reads your CLAUDE.md automatically — it knows who Nina is, who your ideal listener is, how your show notes are structured, and what all seven skills do before you say a word.

What's in the folder

📁 Mindful Parenting Lifestyle/ ├── CLAUDE.md ← The brain. Claude reads this every session. ├── README.md ← Full guide to the system and how to use it. ├── task-setup.md ← Setup guide for your Podcast Content Pack task. └── 📁 skills/ ├── brand-voice/ ← How Nina sounds ├── brand-guidelines/ ← Visual identity (installed in Claude as "visual-identity") ├── podcast-title/ ← 10 title options + SEO keyword ├── podcast-shownotes/ ← Full show notes per your template ├── podcast-instagram/ ← Reel quotes, static quotes, carousels ├── podcast-newsletter/ ← Two newsletter blurb versions └── podcast-orchestrator/ ← Runs all of the above in one go

Note on the visual identity skill

The skill folder is called brand-guidelines on your computer, but during the Reboot Call we installed it in Claude as visual-identity (to work around a naming conflict). The skill works exactly the same — just use /visual-identity to trigger it, or enable it in your skills list.

Updating CLAUDE.md

When something changes — a new episode format, a new offer, updated contact details — you never edit the file directly. Just tell Claude:

Update the CLAUDE.md to reflect that [what's changed]. Also update the README if the folder structure has changed.

Claude makes the edit for you. Simple as that.

Updating a skill

When you want to refine a skill based on feedback, just have a conversation with Claude — tell it what landed, what didn't, show it an example if you have one. At the end of that conversation, say:

Update the podcast-instagram skill to reflect everything we've discussed. Update the installed skill in Claude and save the updated SKILL.md to my Mindful Parenting Lifestyle skills folder on OneDrive.

Claude handles both. If the file and the installed skill drift apart, your outputs won't match what the files say — and you'll wonder why things feel off.

Your Podcast Content Pack Task

This task lives in Claude's Scheduled section. You run it manually whenever you're ready — drop a transcript in your WIP folder and hit Run Now. It runs the full podcast-orchestrator skill and saves four output files directly to your 01 WIP folder on OneDrive.

How to run it

  1. 1Save your episode transcript file to your 01 WIP folder on OneDrive
  2. 2Open Claude Cowork → go to Scheduled → find Podcast Content Pack
  3. 3Click Run Now
  4. 4Claude finds the transcript, generates titles (with a recommended option), runs the full content pack
  5. 5Four files appear in your 01 WIP folder when it's done
  6. 6Review each file, choose what you want to use, and paste into Buzzsprout, Airtable, and Wix

Make sure Claude stays open while it runs

The task needs Claude Cowork to be open and active on your computer while it runs. If you close it mid-run, the task will stop. You can do other things while it's running — just don't close Claude.

The task will produce four files — titles, show notes, social pack, and newsletter — ready to review, edit further with Claude, or copy into your tools.

Quick Tips

Four things that will make a real difference as you get comfortable using this.

1

Update skills in both places

When you refine a skill through Claude, always ask it to save the update to your OneDrive folder too. The version in Claude and the file in your workspace need to stay in sync. Otherwise you iterate in Claude but the file falls behind.

2

Don't let chats run too long

Long chats burn through tokens fast, so Claude has to reread everything each time. When a chat gets long, ask for a handover and start fresh:

Summarise everything we've covered in this chat in a handover document so I can start a fresh conversation.
3

Check your token usage

Go to Settings → your name at the bottom → Usage to see how much you've used in your current session and when it resets. Handy for planning when to do heavier work.

4

Choose your model before you start

Once you've opened a project chat, you can't change the model mid-stream, so pick intentionally at the start:

  • Haiku: quick questions, short tasks, general back-and-forth
  • Sonnet: the everyday workhorse, quality and speed balanced
  • Opus: deep thinking, complex strategy, nuanced analysis
  • Adaptive: Claude decides what each part of the task needs

Using Projects for your podcast

Chat, Projects, and Claude Code — when to use what

Chat — best for quick, one-off questions or tasks that aren't related to your podcast workflow. Memory is on, so Claude knows a bit about you, but your skills aren't loaded.

Projects (where your setup lives) — use this for all podcast content work. By linking your OneDrive podcast folder, your podcast info is always loaded and Claude has full context of your setup from the start of every conversation.

Claude Code — worth exploring when you want to work directly with files on your computer rather than through a chat interface.

What to set up: Creating a separate project for podcast brainstorming and episode planning is good practice — it keeps that thinking and context separate from your content production workflow.
