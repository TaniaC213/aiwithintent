Your Claude Brain

This isn't just a folder of files. It's a system where Claude already knows your business before you type your first message. When you open Claude Cowork and select the Claude Brain folder as your workspace, Claude reads your CLAUDE.md automatically — and knows AJ Harrington Photography inside out from the moment you start.

Always select the top-level Claude Brain folder

When opening a project in Cowork, always select Claude Brain — the whole folder, not a subfolder inside it. The CLAUDE.md at the top level is what Claude reads first. If you select a subfolder (like content/ or skills/), Claude misses that file and loses all your business context.

The brand and products folders are waiting for you

The brand/ and products/ folders are intentionally empty to start. Drop in Jo Wilson's brand guide PDF and any logo files to give your visual identity skill real assets to reference. Add your digital product PDFs (your guides and Lightroom presets) to the products/ folder so Claude has the actual product content when writing launch emails.

Updating CLAUDE.md

When something changes — new pricing, a new service, a different tool, an updated offer — you never edit the file directly. Just tell Claude:

Update the CLAUDE.md to reflect that [what's changed]. Also update the README if the folder structure has changed.

Claude makes the edit for you. Then your whole system knows about it the next time you open Cowork.

Asks you five questions about the month — what happened, tips to share, what's coming, any client wins, anything personal. You answer conversationally (Caps Lock voice shortcut works perfectly here), and Claude drafts your complete newsletter in your voice.

Output saves to content/newsletters in Claude Brain and to the Newsletters folder in your Google Drive so your VA can format it in MailerLite.

How to run it Open the Monthly Newsletter project in Cowork → start a new chat → say:

Let's write the newsletter
Claude will ask questions one at a time. Rough answers are completely fine — it does the shaping.

VA Monthly Briefing

Run once a month  ·  Uses: Google Drive, Gmail, Instagram via Chrome

Starts by auditing your Instagram grid — post types, content themes, what's been going out. Then interviews you about the month ahead (what to push, what's coming up, what the focus is) and produces a strategic brief for your VA.

Output saves to the Monthly Briefing folder inside your existing VA Google Drive folder. Your VA already has access — no extra sharing needed.

Before you run it

Make sure Instagram is open and logged in on your desktop Chrome. Claude uses this to audit your grid — it can see post types and captions, but not private Insights data. If a post stood out in your Insights, screenshot it and drop it into the chat for extra context.

Calendar privacy note

Claude can access your Google Calendar and may pull in private booking details (shoot appointments, personal appointments). If you'd rather keep that out of the VA briefing document, you can remove the calendar question from the project instructions — it's a simple edit. Just open the project in Cowork, click the settings icon, and delete that section from the instructions.

How to run it Open the VA Monthly Briefing project in Cowork → start a new chat → say:

Let's brief my VA, start by asking me the questions from the instructions
The second part of that phrase matters — it tells Claude to interview you first before generating the document.

When to use a project vs. when to use Chat

Use Cowork projects when... Use Claude Chat when...
You want Claude to access Google Drive, Gmail, Calendar, or Instagram You're brainstorming, thinking out loud, or exploring an idea
You want output saved somewhere automatically You just need a quick answer or a draft to copy
Running your newsletter or VA briefing Drafting a caption, writing a quick email, trying something new

Cowork uses more tokens because Claude is doing more. Chat is lighter. Use Chat for thinking, Cowork for doing.

Starting a new project in future

If you want to build something new — a project around client onboarding, a new product launch workflow, or anything else — always create it in Claude Chat first (it runs in the cloud and gets backed up), then import it into Cowork. Open Cowork → Projects → New Project → Import, and point it to your Claude Brain folder.

Quick Tips

Six things that will make a real difference as you get comfortable using this.

1

Update skills in both places

When you refine a skill through Claude, always ask it to save the update to your folder too. The version in Claude and the SKILL.md file need to stay in sync. Otherwise you iterate in Claude but the file falls behind.

2

Don't let chats run too long

Long chats burn through tokens fast and Claude has to reread everything each time. When a chat gets long, ask for a handover and start fresh:

Summarise everything we've covered in this chat in a handover document so I can start a fresh conversation.
3

Check your token usage

Go to Settings → your name at the bottom → Usage to see how much you've used in the current period and when it resets. Good to know before doing heavier Cowork sessions.

4

Choose your model before you start

Pick your model at the start of a chat — you can't change it mid-stream:

  • Haiku: quick questions, short tasks, light back-and-forth
  • Sonnet: the everyday workhorse — quality and speed balanced
  • Opus: deep thinking, strategy, nuanced writing
  • Adaptive: Claude decides what each part of the task needs
5

Ask yourself: can Claude do this for me?

When you're doing something repetitive — copying a Dubsado note into a document, pulling transcript highlights, turning a shoot into a blog post — pause and ask whether Claude could handle it. Give it the outcome you want, not just the task. "I want to turn my session notes into a client blog post" is better than "write a blog post about Sarah."

The more you work with Claude, the more you'll spot where it can take work off your hands.

6

Use Cowork's memory toggle

Inside any Cowork project, there's a memory toggle that shows you what Claude is remembering across sessions. Check it occasionally — it builds up over time and is a good way to see whether Claude has the right picture of your business. If something's wrong, you can clear or correct it.
