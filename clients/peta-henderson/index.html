Your Dragonfly Magic Workspace

This isn't just a folder of files. It's a system where Claude already knows your business before you type your first message. When you open Claude Cowork and select the Dragonfly Magic HQ folder as your workspace, Claude reads your CLAUDE.md automatically and has full context about Dragonfly Magic (your voice, your values, Sofia, your tools) from the moment you start.

These folders are all waiting for you

Every empty folder in your HQ, Clients, Sacred Circles, Reiki, Dance, assets, is there for you to fill in as you see fit, at your own pace. Your colours (Fuschia, Teal and Pink) and fonts (Berkshire Swash for headlines) already live inside the Brand Voice & Guidelines skill, so Claude has your visual identity even before logo files land in assets.

Updating CLAUDE.md

When something changes (a new offer, a folder you've renamed, a new department you want to add) you never edit the file directly. Just tell Claude:

Update the CLAUDE.md to reflect that [what's changed]. Also update the README if the folder structure has changed.

Claude makes the edit for you. Simple as that.

Updating a skill

When you ask Claude to update a skill, it updates the version saved in your Claude account, not the copy sitting in your Dragonfly Magic HQ folder. To keep both in sync, download the updated skill file and replace the one in your skills/ folder yourself.

Update the [skill name] skill to [what needs to change].

Then, in Settings → Skills, click the three dots next to the skill and download it, then replace the old file in your skills/ folder with the new one.

Quick Tips

Five things that will make a real difference as you get comfortable using this.

1

Update skills in both places

Ask Claude to update a skill, then download the new version from Settings → Skills and replace the old file in your skills/ folder yourself. Claude can't save changes back into your OneDrive folder directly, so this step is on you.

2

Don't let chats run too long

Long chats burn through tokens fast, so Claude has to reread everything each time. When a chat gets long, ask for a handover and start fresh:

Summarise everything we've covered in this chat in a handover document so I can start a fresh conversation.
3

Check your token usage

Go to Settings → your name at the bottom → Usage to see how much you've used in your current session and when it resets. Handy for planning when to do heavier work.

4

Choose your model before you start

Once you've opened a project chat, you can't change the model mid-stream, so pick intentionally at the start:

  • Haiku: quick questions, short tasks, general back-and-forth
  • Sonnet: the everyday workhorse, quality and speed balanced
  • Opus: deep thinking, complex strategy, nuanced analysis
  • Adaptive: Claude decides what each part of the task needs
5

Chat still works on files, even outside a project

You don't need a project for everything. If it's a one-off or you're not sure yet where something belongs, just start a plain chat and add a file with the plus button. If it grows into something ongoing, like your dance chats already have, you can move it into a project later without losing anything.

Making Changes to Your HQ

You're welcome to reshape this however suits how you actually work. Renaming folders, merging two into one, adding a new department, none of that breaks anything, as long as you follow the steps below so the rest of your setup knows about the change too. Nothing here happens automatically just because you renamed something, Claude only finds out what you tell it.

  1. 1 Make the change in your OneDrive first. Rename, merge, split or add the folder exactly how you want it to actually exist. Do this before telling Claude anything, your real folder structure is always the source of truth, not the other way around.
  2. 2 Switch to Cowork, link your HQ folder for that session, and tell Claude exactly what changed. In the chat box, toggle from Chat to Cowork. Underneath, you'll see "Project or folder", hover over it and click to select the folder you want linked for that session, choose your whole Dragonfly Magic HQ. This isn't the same as attaching a single file, it gives Claude proper access to look at your actual folders. Then describe the change precisely: "I merged 03 - Workshops & Masterclasses and 04 - Sacred Circles into one folder called 03 - Workshops" is useful. "I changed some folders around" isn't, Claude can't act on that.
  1. 3 Ask Claude to update CLAUDE.md and README.md to match. These two files are what tell Claude where everything lives and what each folder is for. Once Claude can see the real folder structure (from Step 2), ask it directly: "Please update CLAUDE.md's routing table and README.md's folder map to reflect this change." It'll rewrite both for you.
  2. 4 If a Project was already pointed at the folder that changed, re-link it yourself. This is the one step Claude can't do on your behalf, no matter how clearly you explain the change. A Project's linked folder is set inside Claude's own Project settings, not in a file, so it doesn't update itself. If you've renamed or moved a folder that a Project already points to (like Blog or Workshops & Masterclasses), open that Project, go to its settings, and re-select the folder in its new location.
  3. 5 Check whether any of your skills mention the old folder by name. Your Blog Writing skill saves its output to a specific folder path, so if you ever restructure Content, ask Claude: "Does this change affect any of my skills?" If it does, it'll offer to update the skill, and the same rule applies as any skill update, download the new version from Settings → Skills and replace the old file in your skills folder yourself, so your saved copy and your live skill stay in sync.

That's the whole process. It looks like more steps written out than it feels like doing it, most changes are really just Steps 1 through 3. Steps 4 and 5 only apply if a Project or a skill already depended on the specific thing you changed.
