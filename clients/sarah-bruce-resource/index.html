Updating a skill

When you refine a skill through Claude, ask it to save a copy of the updated version into 05 My Claude Setup/skills in your Drive. Claude can create a new file there through your connected Drive, but it can't overwrite the old one directly — so once the new copy is in, delete the outdated one yourself so you're not left with two versions.

Update the [skill name] skill to [what needs to change]. Then save a copy of the updated version into 05 My Claude Setup/skills in my Google Drive.

Your Booking Capture Task

This lives in Claude's Scheduled section, named Sarah Bruce TidyCal Booking Capture, set to manual — nothing runs on its own, you trigger it yourself whenever you know a booking's come in.

How to run it

  1. 1Cowork → Scheduled
  2. 2Open Sarah Bruce TidyCal Booking Capture
  3. 3Click Run now
  4. 4It checks Gmail for a new TidyCal booking, pulls out the client's answers to your 11 questions, and files them into a prep folder in your Drive

Quick Tips

Five things that'll make a real difference as you get comfortable using this.

1

Update skills in both places

When you refine a skill through Claude, ask it to also give you the file to save over your Drive copy. Otherwise you iterate in Claude but your saved copy falls behind.

2

Don't let chats run too long

Long chats burn through tokens fast. When one's getting long, ask for a handover and start fresh:

Summarise everything we've covered in this chat in a handover document so I can start a fresh conversation.
3

Check your token usage

Settings → your name at the bottom → Usage. Handy to check before a heavier session.

4

If a connector says it's expired, just reconnect it

We hit this twice on the call — Google Drive and Gmail both needed reauthorising partway through. It's not something you did wrong, connections just lapse sometimes. Settings → Connectors → disconnect and reconnect the one giving trouble.

5

Give yourself small, regular practice runs

You said it yourself on the call — thirty minutes a day, even just making up a test appointment and seeing what Claude does with it, will make this feel natural far faster than one long session ever could.
